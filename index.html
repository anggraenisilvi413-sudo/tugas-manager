    Tentang Proyek Ini

    Git dan GitHub

    Git mencatat riwayat perubahan kode lewat commit. Branch dipakai untuk mengerjakan fitur secara terpisah, lalu digabung ke branch utama dengan merge. GitHub menyimpan repository secara online dan menjadi tempat Pull Request untuk meninjau perubahan sebelum digabung.

    npm

    npm adalah pengelola paket. File package.json mencatat dependencies (paket yang dibutuhkan aplikasi saat berjalan) dan devDependencies (alat bantu pengembangan seperti Vite dan TypeScript). Versi paket memakai semantic versioning MAJOR.MINOR.PATCH; tanda ^ mengizinkan pembaruan MINOR dan PATCH. Perintah npm scripts yang dipakai: dev, build, dan preview.

    TypeScript

    TypeScript adalah JavaScript dengan sistem tipe sehingga kesalahan ketahuan sebelum aplikasi dijalankan. Di kode ini dipakai tipe primitif (string, number, boolean), array, interface Tugas, type alias dan union type Status, serta generics pada kelas Penyimpanan<T>.

    Vite

    Vite adalah alat pengembangan yang menyediakan dev server cepat dan proses build untuk menghasilkan file siap diunggah.

    Environment variables

    Nama dan versi aplikasi dibaca dari file .env (VITE_APP_NAME dan VITE_APP_VERSION). File .env masuk .gitignore agar tidak diunggah ke GitHub, dan .env.example menjadi contoh. Variabel berawalan VITE_ ikut tertanam di hasil build, jadi hanya boleh berisi data tidak rahasia.

    Compiler, transpiler, dan bundler

    Compiler TypeScript (tsc) memeriksa tipe. Transpiler mengubah kode TypeScript menjadi JavaScript yang dipahami browser (Vite memakai esbuild untuk ini). Bundler menggabungkan banyak modul dan aset menjadi sedikit file yang dioptimalkan (Vite memakai Rollup saat build).
